I build web apps with **TypeScript, Next.js and PostgreSQL**, put them in **Docker**, ship them to a **Linux VPS** behind Traefik with GitHub Actions, and write docs so the next person has an easier time. On the side I poke at distributed systems to see where they break.

## 🔨 currently building

| project | what it is |
|---|---|
| [grimo](https://github.com/diegorezm/grimo) | social network for readers: shelves, reviews, feed and a monthly reading recap · web + mobile on Cloudflare |
| [meu-edital](https://github.com/diegorezm/meu-edital) | study planner for public exams: import notices with AI help, plan the week, track sessions and reviews |
